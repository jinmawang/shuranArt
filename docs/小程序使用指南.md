# 书染美术 小程序使用指南

---

## 一、概述

「书染美术」是一款面向画室学员及家长的微信小程序，提供画室介绍、课程浏览、活动参与、幸运抽奖、学生作品展示、拼团报课等功能。同时内置管理后台，方便画室老师进行内容管理和运营。

---

## 二、用户端功能

### 1. 首页

首页是小程序的主入口，包含以下模块：

- **重力小球动画**：屏幕上方有「书」「染」「美」「术」四个小球，会随手机倾斜方向移动，点击可触发弹跳效果。
- **轮播图**：展示画室动态、学生作品、活动通知等，点击可查看详情。
- **画室简介卡片**：显示画室名称和标语。
- **功能入口（四宫格）**：
  - **画室介绍**：查看画室详情、老师信息、地址导航。
  - **课程介绍**：浏览所有课程。
  - **活动中心**：查看正在进行的活动和拼团。
  - **幸运抽奖**：进入抽奖转盘。
- **热门活动**：展示当前进行中的活动和拼团活动，点击可直接参与。
- **精选作品**：瀑布流展示已加精的学生作品。
- **联系老师**：底部展示画室微信二维码，方便家长添加。

---

### 2. 幸运抽奖

进入方式：底部Tab栏「抽奖」或首页四宫格「幸运抽奖」。

**抽奖规则：**
- 每次浏览活动详情页 → 获得 **1次** 抽奖机会
- 每次成功分享活动给好友 → 获得 **1次** 抽奖机会
- 每个活动最多获得 **6次** 抽奖机会
- 每 **8次** 抽奖保底获得一等奖或二等奖
- 中奖后请在 **2个月内** 到画室线下兑换

**操作步骤：**
1. 确认有抽奖次数（页面顶部显示剩余次数）
2. 点击转盘中央的指针
3. 等待转盘停止，查看中奖结果
4. 中奖奖品可在「我的」页面查看兑换状态

---

### 3. 活动中心

进入方式：首页四宫格「活动中心」。

- 展示所有进行中的 **普通活动** 和 **拼团活动**
- 拼团活动带有「拼团」标签
- 点击普通活动 → 进入活动详情页（可获得抽奖机会、分享活动）
- 点击拼团活动 → 进入拼团详情页

---

### 4. 活动详情

- 查看活动标题、封面图、时间、详细描述
- **首次访问**自动获得1次抽奖机会
- 点击「分享给好友」按钮可分享活动，好友点击后你将额外获得1次抽奖机会
- 点击「去抽奖」直接跳转抽奖页面
- 底部显示画室微信号，可一键复制

---

### 5. 拼团

进入方式：首页热门活动中的拼团活动，或活动中心。

**拼团流程：**

**发起拼团（开团）：**
1. 进入拼团活动页面
2. 点击底部「我要开团」按钮
3. 授权微信手机号（首次需要）
4. 开团成功后，分享链接邀请好友加入

**加入拼团：**
1. 通过好友分享的链接进入，或在拼团页面找到进行中的团
2. 点击「加入拼团」按钮
3. 授权微信手机号（首次需要）
4. 加入成功

**成团通知：**
- 当团队人数达到要求时自动成团
- 所有团员会收到微信订阅消息通知
- 成团后请联系老师线下缴费

**注意事项：**
- 每个拼团活动每人只能参与一次（开团或加入）
- 团满后无法再加入
- 活动过期后无法开团或加入

---

### 6. 作品墙

进入方式：底部Tab栏「作品墙」。

- 按时间线展示所有已审核通过的学生作品
- 点击孩子姓名可查看该孩子的作品集
- 点击作品图片可全屏预览
- 右下角浮动按钮可上传新作品

**上传作品流程：**
1. 首次使用需先添加孩子信息（姓名 + 申请理由）
2. 等待管理员审核通过孩子信息
3. 审核通过后，选择孩子 → 拍照或选择图片 → 填写描述（可选）→ 提交
4. 作品审核通过后将展示在作品墙上

**限制：**
- 每个用户最多添加 **3个** 孩子
- 每个孩子最多保留 **30件** 作品

---

### 7. 画室介绍

进入方式：首页四宫格「画室介绍」。

包含三个Tab：

- **介绍**：画室名称、标语、详细介绍、画室环境照片/视频
- **老师**：所有老师的头像、姓名、简介、微信号（可复制）
- **位置**：地图显示画室位置，可一键拨打电话或打开地图导航

---

### 8. 课程介绍

进入方式：首页四宫格「课程介绍」。

- 顶部分类筛选（如：素描、水彩、油画等）
- 课程卡片展示封面图、名称、描述
- 点击课程可查看详情

---

### 9. 我的

进入方式：底部Tab栏「我的」。

- **头像与昵称**：点击可修改头像和昵称
- **数据展示**：积分 | 抽奖次数
- **最近中奖记录**：展示最近5条中奖记录，包含：
  - 奖品名称和等级（一等奖/二等奖）
  - 中奖时间
  - 状态：待兑换 / 已兑换 / 已过期 / 已作废
- **分享邀请**：分享小程序给好友
- **管理后台**：仅管理员可见，点击进入后台管理

---

### 10. 分享功能

小程序支持多种分享方式：

- **活动分享**：分享活动详情页给好友，可获得抽奖机会
- **拼团分享**：分享拼团链接邀请好友加入
- **作品分享**：分享孩子作品或作品时间线
- **小程序分享**：通过「我的」页面分享小程序

从分享链接进入的用户，页面顶部会显示🏠图标，点击可返回首页。

---

## 三、管理后台

管理员在「我的」页面可看到「管理后台」入口。

### 管理模块一览

| 模块 | 功能 |
|------|------|
| **画室配置** | 设置画室名称、标语、介绍、地址、电话、微信号、经纬度、二维码、环境图片等 |
| **老师管理** | 添加/编辑/删除老师信息（姓名、头像、简介、微信号） |
| **活动管理** | 创建/编辑/删除活动，设置时间、封面图、分享图、分享次数上限 |
| **课程管理** | 添加/编辑/删除课程，设置分类、封面图、描述 |
| **奖品管理** | 设置抽奖奖品、等级、概率权重、图标 |
| **轮播图管理** | 添加/排序/删除首页轮播图 |
| **管理员管理** | 邀请/移除管理员，查看管理员昵称和手机号 |
| **核销管理** | 查看中奖记录，进行兑换核销或作废处理；积分兑换管理 |
| **作品审核** | 审核孩子注册申请和作品上传，支持加精操作 |
| **拼团管理** | 创建/编辑/删除拼团活动，查看各团队成员信息（昵称、手机号） |

### 邀请管理员

1. 在「管理员管理」页面点击「邀请管理员」
2. 系统生成邀请链接
3. 将链接分享给目标用户
4. 对方点击链接即可成为管理员

### 核销奖品

1. 进入「核销管理」
2. 在「奖品记录」Tab中找到待兑换的记录
3. 用户到店后，点击「核销」按钮确认兑换
4. 如需作废，点击「作废」按钮

### 拼团管理

1. 进入「拼团管理」
2. 点击「新建拼团」，填写：课程名称、成团人数、价格、活动图片、分享图片、起止时间
3. 创建后可在列表中查看所有团队的成员详情
4. 每个成员显示微信昵称和手机号，方便联系

## 四、常见问题

**Q: 如何获得抽奖机会？**
A: 浏览活动详情页可获得1次，分享活动给好友可获得1次，每个活动最多6次。

**Q: 中奖后怎么兑换？**
A: 到画室线下找老师兑换，请在2个月有效期内使用。

**Q: 拼团成功后怎么缴费？**
A: 拼团成功后请联系画室老师线下缴费，拼团仅为线上组队。

**Q: 为什么上传的作品看不到？**
A: 作品需要管理员审核通过后才会显示在作品墙上，请耐心等待。

**Q: 为什么无法添加更多孩子？**
A: 每个用户最多可添加3个孩子。

**Q: 拼团时为什么需要授权手机号？**
A: 手机号用于拼团成功后老师联系您安排课程，仅管理员可见。
