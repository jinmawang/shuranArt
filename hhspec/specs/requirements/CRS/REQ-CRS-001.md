# REQ-CRS-001: 课程介绍系统

## 1. 需求概述

| 属性 | 值 |
|------|-----|
| 需求编号 | REQ-CRS-001 |
| 需求类型 | 功能需求 |

| 状态 | 新增功能 |

## 2. 用户故事

### US-CRS-001: 课程列表浏览
**As a** 潜在学员/家长
**I want** 浏览画室提供的所有课程
**So that** 我能了解课程体系并选择适合的课程

### US-CRS-002: 课程详情查看
**As a** 潜在学员/家长
**I want** 查看某个课程的详细信息（价格、时长、适合人群、教学内容）
**So that** 我能判断这个课程是否适合我/孩子

### US-CRS-003: 课程分类筛选
**As a** 潜在学员/家长
**I want** 按类别筛选课程（如素描、水彩、油画等）
**So that** 我能快速找到感兴趣的课程类型

### US-CRS-004: 课程管理
**As a** 画室管理员
**I want** 在管理后台添加、编辑、上下架和排序课程
**So that** 我能及时更新课程信息

## 3. EARS 范式系统行为

### EARS-CRS-001: 课程列表
**When** 用户进入课程列表页
**the system shall** 展示所有状态为上架(active)的课程，按 sort_order 升序排列，每项显示课程名称、价格、时长、封面图和适合人群标签。

### EARS-CRS-002: 分类筛选
**When** 用户选择某个课程类别进行筛选
**the system shall** 仅展示该类别下的课程，保持排序不变。

### EARS-CRS-003: 课程详情
**When** 用户点击某个课程
**the system shall** 展示课程详情页，包含：课程名称、封面图、价格（格式：¥X,XXX）、时长、适合人群、课程描述（富文本）、课程类别。

### EARS-CRS-004: 首页课程入口
**When** 用户在首页查看
**the system shall** 在首页展示课程快捷入口区域，显示最多4个推荐课程缩略卡片，点击跳转到课程列表页。

### EARS-CRS-005: 管理后台CRUD
**When** 管理员在课程管理页面操作
**the system shall** 支持：新增课程（填写所有字段）、编辑课程信息、上架/下架切换、拖拽排序、删除课程。

## 4. Gherkin 验收标准

### AC-CRS-001: 课程列表展示
```gherkin
Feature: 课程介绍

  Scenario: 查看课程列表
    Given 存在3个上架课程（素描基础班/¥2000、水彩提高班/¥3000、油画大师班/¥5000）
    And 按sort_order排列为：素描→水彩→油画
    When 用户进入课程列表页
    Then 按序显示3个课程卡片
    And 每个卡片显示封面图、名称、价格、时长

  Scenario: 空课程列表
    Given 没有任何上架的课程
    When 用户进入课程列表页
    Then 显示空状态提示"暂无课程信息"
```

### AC-CRS-002: 分类筛选
```gherkin
  Scenario: 按类别筛选课程
    Given 存在"素描"类2个课程和"水彩"类1个课程
    When 用户选择"素描"类别
    Then 仅显示2个素描类课程
    When 用户选择"全部"
    Then 显示所有3个课程
```

### AC-CRS-003: 课程详情
```gherkin
  Scenario: 查看课程详情
    Given 存在课程"素描基础班"
    When 用户点击该课程
    Then 显示详情页，包含：名称、封面图、价格¥2,000、时长3个月、适合人群"零基础学员"、详细描述
```

### AC-CRS-004: 管理后台
```gherkin
  Scenario: 管理员添加课程
    Given 管理员在课程管理页面
    When 填写课程名称"国画入门班"、类别"国画"、价格2500、时长"2个月"、适合人群"零基础"
    And 上传封面图
    And 点击保存
    Then 课程创建成功

  Scenario: 管理员下架课程
    Given 存在上架课程"国画入门班"
    When 管理员切换为下架状态
    Then 该课程在用户端不再显示
    And 管理端仍可见，标记为"已下架"
```

## 5. 边界场景清单

| # | 场景 | 预期行为 |
|---|------|---------|
| B1 | 课程价格为0（免费体验课） | 正常显示"免费" |
| B2 | 课程描述为空 | 详情页描述区域隐藏 |
| B3 | 课程封面图加载失败 | 显示默认占位图 |
| B4 | 所有课程都被下架 | 列表页显示空状态 |
| B5 | 课程类别不存在任何课程 | 筛选后显示空状态"该类别暂无课程" |
| B6 | 删除已有课程 | 确认弹窗后删除，列表刷新 |
| B7 | 价格超大数值 | 正确格式化显示（如¥10,000） |
